# Acknowledgements

SwiftCloud is built on the work of open-source communities around the world. We recognise the projects, people and communities whose software and ideas power the SwiftCloud ecosystem.

## Open-Source Software

SwiftCloud's developer tools — including the [SwiftCloud CLI](https://github.com/swiftcloud-platform/cli) — are built with the following open-source projects:

- **[Go](https://go.dev)** — the language behind our command-line tooling.
- **[Cobra](https://github.com/spf13/cobra) & [pflag](https://github.com/spf13/pflag)** — the command framework and flag parsing behind the SwiftCloud CLI experience.
- **[AWS SDK for Go v2](https://github.com/aws/aws-sdk-go-v2)** — together with [smithy-go](https://github.com/aws/smithy-go), it powers our S3-compatible object storage integration.
- **[oapi-codegen](https://github.com/oapi-codegen/oapi-codegen)** — generates the type-safe API client our tools use to talk to the SwiftCloud platform.
- **[yaml.v3](https://gopkg.in/yaml.v3)** — configuration file handling in the CLI.

Our release pipeline and code quality standards also rely on [GoReleaser](https://goreleaser.com), [golangci-lint](https://golangci-lint.run) and [GitHub Actions](https://github.com/features/actions).

## People & Communities

- The maintainers and contributors of every project listed above, whose sustained work we depend on every day.
- The wider **Go community** — for the language, the tooling and the welcoming ecosystem around it.
- Everyone who reports issues, suggests improvements and contributes to SwiftCloud's open-source repositories.
